# Data Dictionary: DNA Cancer Classification

This document describes the schema, fields, and metadata identified in the original college project artifacts and legacy notebooks (`legacy/old_notebooks/`).

> [!WARNING]
> Several aspects of the biological provenance, accession identifiers, and sequencing protocols of the original dataset are **unverified** and were not documented in the legacy code.

---

## 1. Identified Dataset Fields

### Raw / Tabular Dataset Schema (`data/raw/`)

| Field Name | Data Type | Description | Status |
| :--- | :--- | :--- | :--- |
| `id` | `string` | Sample identifier or record accession number. In legacy conversion scripts, this was extracted from FASTA headers or defaulted to row index. | Partially Verified (Legacy scripts parsed FASTA headers; raw Google Drive files not locally hosted) |
| `sequence` | `string` | Raw nucleotide sequence string (A, C, G, T, N). Sequences vary in length depending on the source gene or fragment. | **Verified in legacy scripts** |
| `len` | `integer` | Sequence character length (`len(sequence)`). | **Verified in legacy scripts** |
| `cancer` | `string` | Cancer type label (ground truth target classification). | **Verified in legacy scripts** |

## 3. Interim & Processed Fields (`data/interim/`, `data/processed/`)

| Field Name | Data Type | Description |
| :--- | :--- | :--- |
| `cleaned_sequence` | `string` | Uppercase, whitespace-stripped nucleotide sequence containing only allowed IUPAC characters (`ACGTN`). |
| `kmers` | `string` or `list` | Overlapping $k$-mers ($k=6$, stride $=1$). In processed form, joined into a space-separated string of tokens. |
| `cancer_encoded` | `integer` | Integer class label ($0$ to $3$) generated via `LabelEncoder`. |
| `feature_vector` | `ndarray` (sparse/dense) | $N$-gram count or TF-IDF vector matrix generated by `CountVectorizer(ngram_range=(4, 4))`. |

## 4. Unverified Metadata & Open Questions

The following critical bioinformatics details were **not** documented in the original second-year project:

1. **Biological Origin & Assembly:**
   - Are sequences derived from whole genomes, exomes, cDNA, or specific targeted biomarker genes (e.g., TP53, KRAS, BRCA1)?
   - Reference genome assembly (e.g., GRCh37/hg19 vs. GRCh38/hg38) is unknown.
2. **Sequencing Technology:**
   - Sequencing platform (Illumina short-read, Sanger, PacBio, or Oxford Nanopore) is unspecified.
   - Base quality scores (FASTQ Phred scores) are unavailable; only FASTA/CSV sequences exist.
3. **Data Source & Licensure:**
   - The original files were hosted on Google Drive (`legacy/Data.txt`). The original public database source (NCBI GenBank, TCGA, GEO, or COSMIC) and license terms remain unverified.
4. **Clinical Context:**
   - No clinical covariates (patient age, sex, tumor stage, somatic vs. germline origin) were tracked.
