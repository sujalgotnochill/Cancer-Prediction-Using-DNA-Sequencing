# Command-Line Scripts

This directory houses CLI executable scripts for orchestrating data processing, training, evaluation, and prediction.

## Planned Entrypoints (Phase 2 & 3)

- `train.py`: CLI script to execute `TrainingPipeline`.
- `evaluate.py`: CLI script to run evaluation metrics on held-out test datasets.
- `predict.py`: CLI script for command-line inference on individual DNA sequences or FASTA files.
